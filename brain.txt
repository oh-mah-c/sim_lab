# PART I — ARCHITECTURAL OBJECTIVES

## 1. System Definition

Replace the existing monolithic CL-1 neural block with a complete modular neural architecture.

The system must simulate the major functional structures of a human brain, their interactions, and their effects on an NPC's behavior.

The architecture must support:

1. Sensory perception.
2. Multisensory integration.
3. Attention and salience detection.
4. Reflexes and automatic responses.
5. Motor coordination and movement learning.
6. Homeostatic regulation.
7. Emotional processing.
8. Reward and punishment learning.
9. Short-term and working memory.
10. Episodic memory.
11. Semantic memory.
12. Procedural memory.
13. Associative learning.
14. Spatial cognition and navigation.
15. Prediction and prediction-error processing.
16. Goal formation and prioritization.
17. Decision-making and action selection.
18. Multi-step reasoning and planning.
19. Language acquisition and communication.
20. Sleep, forgetting and memory consolidation.
21. Neural plasticity and individual development.
22. Heritable neural architecture and behavioral predispositions.

The brain must not contain predefined knowledge about the world.

It must acquire knowledge through sensory observations, experiences, experimentation, memory and communication with other agents.

## 2. Architectural Invariants

The following requirements are mandatory.

### 2.1 Integer-only computation

All neural computations must use integer arithmetic.

Allowed:
- int8_t
- uint8_t
- int16_t
- uint16_t
- int32_t
- uint32_t
- int64_t
- uint64_t

Forbidden:
- float
- double
- floating-point SIMD
- floating-point neural activation
- floating-point probability calculations
- floating-point decay functions

All continuous-like biological quantities must use documented fixed-point integer representations.

Every operation must have explicitly defined overflow, saturation and rounding behavior.

### 2.2 Deterministic execution

Identical initial states and identical input sequences must produce identical outputs.

Required invariants:

- dev == release
- single-thread == multi-thread
- t1 == t8
- save/load == uninterrupted simulation
- identical genome + identical experience = identical neural evolution

Parallel processing must never introduce nondeterministic accumulation order.

### 2.3 CPU efficiency

The architecture must support thousands of independently simulated NPCs.

Requirements:

- No heap allocation in neural hot paths.
- Preallocated BrainArena.
- Sparse spike propagation.
- Event-driven module activation.
- Multi-rate scheduling.
- Cache-friendly SoA storage.
- AVX2 acceleration.
- Bounded neural processing budgets.
- No unnecessary full-brain updates.
- No unbounded mental simulation loops.

### 2.4 Separation of responsibilities

The following must remain separate:

- Neural computation.
- Anatomical organization.
- Memory storage.
- World knowledge.
- Sensory encoding.
- Motor execution.
- Behavioral decision-making.
- Genetic inheritance.

The neural system must not directly modify world state.

It produces neural signals and action preferences. The existing action system validates and executes actions.

Implement 12 anatomical-functional systems.

These systems are independent processing modules connected through a sparse directed connectome.

Each module contains:
- Neural population.

- Firing thresholds.
- Refractory states.
- Local synaptic connections.
- Incoming and outgoing tracts.
- Activation priority.

- Plasticity parameters.
- Module-specific state.

The module architecture must not assume that all regions contain the same number of neurons.

Use configurable neuron populations and bounded memory allocation.

# PART III — NEURAL SUBSTRATE

## 5. Neuron Model

Implement integer-based Leaky Integrate-and-Fire neurons.

Each neuron stores:

- int16_t membrane_potential.
- int16_t threshold.
- int16_t reset_potential.
- uint8_t refractory_remaining.
- uint8_t neuron_flags.
- uint8_t activation_state.
- uint8_t plasticity_class.

Neuron parameters must be configurable and heritable.

### 5.1 LIF update

For non-refractory neurons:

1. Apply membrane leak.
2. Receive synaptic inputs.
3. Apply modulation.
4. Compare against firing threshold.
5. Generate spike if threshold is reached.
6. Reset membrane.
7. Start refractory period.

Example:

```cpp
membrane -= membrane >> leak_shift;

membrane += synaptic_input;

if (membrane >= threshold) {
    spike_mask |= (1ULL << neuron_index);
    membrane = reset_potential;
    refractory = refractory_period;
}
```

Define signed shift behavior explicitly. Use deterministic division or an equivalent defined integer operation where compiler differences could affect results.

### 5.2 Neuron populations

Support multiple functional neuron classes:

- Excitatory.
- Inhibitory.
- Fast-response.
- Slow-response.
- Modulatory.
- Memory-associated.
- Motor-associated.

Inhibitory and excitatory effects must be represented explicitly.

Do not implement every synapse as positive accumulation.

### 5.3 Sparse firing

Use uint64_t bitmasks for groups of 64 neurons.

```cpp
struct SpikeGroup {
    uint64_t active_mask;
};
```

Support efficient bit enumeration using:

```cpp
while (active) {
    const uint32_t index = __builtin_ctzll(active);
    active &= active - 1;
}
```

All iteration orders must be deterministic.

## 6. Synaptic Architecture

Implement sparse directed synaptic connections.

Each connection contains:

- Source neuron.
- Target neuron.
- Signed weight.
- Connection type.
- Delay.
- Plasticity flags.
- Modulation sensitivity.

Use compact fixed-capacity adjacency structures.

Recommended storage:

```cpp
struct Synapse {
    uint16_t target;
    int8_t weight;
    uint8_t flags;
    uint8_t delay;
};
```

Use CSR-style adjacency indexing:

- row_offsets[source]
- synapse_data[]
- synapse_count

The connection structure must support intra-module and inter-module connections.

### 6.1 Connection categories

- Local excitatory connections.
- Local inhibitory connections.
- Feedforward connections.
- Feedback connections.
- Recurrent connections.
- Long-range association connections.
- Modulatory connections.

### 6.2 Connection delays

Support deterministic delayed propagation.

Use fixed-size ring buffers.

No dynamic queues in the hot path.

### 6.3 Connectome heritability

BrainGenome must contain:

- Module population configuration.
- Neural thresholds.
- Leak parameters.
- Refractory parameters.
- Connection density.
- Inter-module tract weights.
- Excitatory/inhibitory distribution.
- Plasticity parameters.
- Neuromodulator sensitivity.
- Cognitive processing biases.

Crossover and mutation must operate on bounded, validated gene structures.

Individual learning must not modify the inherited genome unless an explicit evolutionary mechanism allows it.

- It receives a new sensory event.
- An incoming spike arrives.
- Its internal state crosses an activation threshold.
- A connected module requests processing.

Implement activation propagation with bounded work queues.

Duplicate activation requests must be coalesced.

Modules must not repeatedly activate each other indefinitely within one simulation tick.

# PART VI — MEMORY ARCHITECTURE

## 10. Memory Subsystems

Memory must be independent from the neural substrate.

Use neural activity to encode, retrieve, associate and consolidate memory records.

Implement five primary memory systems.

### 10.1 Sensory Memory

Very short-lived representations of recent sensory information.

Responsibilities:
- Retain recent observations.
- Support temporal continuity.
- Provide input for attention.
- Support recognition of changing stimuli.

Must have a bounded capacity and deterministic expiration.

### 10.2 Working Memory

Temporary active information used during cognition.

Required slots:

- Current goal.
- Current situation.
- Relevant objects.
- Active threats.
- Retrieved memories.
- Candidate actions.
- Current planning step.
- Expected outcomes.

Support:
- Updating.
- Replacement.
- Interference.
- Decay.
- Attention-based retention.

Capacity must be configurable and bounded.

### 10.3 Episodic Memory

Stores experiences and events.

Example:

```text
Event:
NPC observed another NPC using a stone.

Context:
Location A.
Time T.
Object: Stone.
Action: Striking.
Outcome: Material fractured.

Emotional Context:
Surprise: High.

Confidence:
Observed directly.
```

The NPC must remember what happened without automatically understanding why it happened.

### 10.4 Semantic Memory

Stores acquired knowledge and relationships.

Examples:

- Object properties.
- Material characteristics.
- Spatial knowledge.
- Learned concepts.
- Causal relationships.
- Social knowledge.
- Language concepts.

Semantic knowledge must originate from experience, inference, experimentation or communication.

Support confidence and contradictory beliefs.

### 10.5 Procedural Memory

Stores learned skills and action patterns.

Examples:

- Walking.
- Running.
- Climbing.
- Tool manipulation.
- Material processing.
- Combat movements.
- Repeated work procedures.

Procedural memory must improve through repeated successful execution and error correction.

### 10.6 Memory forgetting

Forgetting must be a natural process.

Retention must depend on:

- Recency.
- Repetition.
- Emotional importance.
- Retrieval frequency.
- Semantic associations.
- Consolidation strength.
- Memory interference.

Never delete memories randomly.

Forgetting must be deterministic and based on explicit memory rules.

## 11. Memory Retrieval

Implement indexed retrieval.

Avoid scanning all memories on every cognitive operation.

Use bounded associative indices and deterministic candidate ranking.

Retrieval scores may consider:

- Semantic similarity.
- Spatial relevance.
- Temporal relevance.
- Emotional relevance.
- Contextual relevance.
- Retrieval history.

Use integer scoring.

Return both retrieved information and confidence.

## 12. Sleep and Consolidation

Implement sleep as an internal biological processing state.

During sleep:

- Reduce active sensory processing.
- Suspend unnecessary cognitive rollouts.
- Replay selected episodic memories.
- Strengthen useful associations.
- Consolidate procedural learning.
- Update semantic knowledge.
- Resolve selected memory conflicts.
- Apply forgetting and interference rules.

Dream replay must not create knowledge without an existing memory basis.

Dreams may recombine previously experienced elements but cannot introduce arbitrary external facts.

# PART VII — LEARNING AND NEUROPLASTICITY

## 13. Synaptic Plasticity

Implement integer-only plasticity.

Support:

- Hebbian learning.
- Spike-Timing-Dependent Plasticity (STDP).
- Reward-modulated plasticity.
- Error-driven learning.
- Association strengthening.
- Synaptic weakening.
- Long-term potentiation.
- Long-term depression.

### 13.1 STDP

Maintain bounded pre- and post-synaptic traces.

Use deterministic integer trace decay.

When a relevant spike relationship occurs, update synaptic weight.

```cpp
weight += plasticity_delta;
weight = clamp(weight, min_weight, max_weight);
```

The timing window and update coefficients must be configurable and heritable.

### 13.2 Reward-Modulated Learning

Use dopamine modulation to influence learning.

Reward signals must be generated from experienced outcomes, not arbitrary positive reinforcement.

Implement a bounded reward-prediction error:

```text
Prediction Error =
Actual Outcome Value - Expected Outcome Value
```

Use this signal for reinforcement learning.

### 13.3 Learning from failure

Failure must produce learning signals.

Examples:

- Failed movement.
- Failed material processing.
- Incorrect predictions.
- Social rejection.
- Injury.
- Resource acquisition failure.

The NPC must be able to modify future behavior based on repeated failure.

### 13.4 Learning from observation

Support observational learning.

An NPC can observe another agent's behavior, associate actions with outcomes and later attempt similar behavior.

Observation alone must not guarantee successful skill acquisition.

### 13.5 Learning through experimentation

Support:

1. Problem recognition.
2. Hypothesis formation.
3. Experiment selection.
4. Action execution.
5. Outcome observation.
6. Prediction comparison.
7. Memory encoding.
8. Knowledge revision.

This process must use Sunnyworld's existing discovery and material systems.

The brain must not contain a predefined crafting or technology database.

# PART IX — COGNITIVE ARCHITECTURE

## 15. Attention and Salience

Implement a shared attention controller.

The controller receives requests from sensory, emotional and cognitive systems.

Rank information using deterministic integer scores.

Attention must be limited by a configurable processing budget.

High-priority information can interrupt lower-priority processing.

## 16. Prediction System

Implement predictive processing.

Each relevant cognitive system may maintain predictions about:

- Sensory input.
- Environmental changes.
- Object behavior.
- Movement outcomes.
- Social interactions.
- Action consequences.

When new information arrives:

1. Retrieve the corresponding prediction.
2. Compare prediction with observation.
3. Calculate prediction error.
4. Update relevant memory.
5. Generate learning signals.
6. Trigger additional processing if necessary.

Predictions must never be treated as confirmed world facts.

- Priority.
- Current progress.
- Preconditions.
- Expected outcome.
- Failure conditions.
- Expiration conditions.
- Associated memories.

Goals may conflict.

# PART XIII — CPU EXECUTION ARCHITECTURE

## 24. Multi-Rate Scheduler

Implement a deterministic neural scheduler.

| System | Processing frequency |
|---|---|
| Brainstem | Every tick |
| Thalamus | Every tick / sensory event |
| Sensory Cortex | Sensory event |
| Motor Cortex | Motor event |
| Cerebellum | Movement event / every tick while moving |
| Hypothalamus | Every 4 ticks / homeostatic event |
| Basal Ganglia | Every 4 ticks / action event |
| Amygdala | Salient event |
| Hippocampus | Memory event / rest |
| Association Cortex | Event-driven |
| Prefrontal Cortex | Conditional |
| Language Network | Communication event |

Scheduler must support event coalescing and bounded activation propagation.

## 25. BrainArena

Preallocate neural memory.

Required allocations:

- Neuron state.
- Spike masks.
- Synapse storage.
- Delayed spike buffers.
- Module states.
- Neuromodulator states.
- Plasticity traces.
- Working memory.
- Memory indices.
- Event queues.
- Cognitive rollout scratch buffers.

Use 64-byte alignment.

No heap allocation during normal neural processing.

Memory capacities must be configurable per NPC class.

Provide a minimal profile for low-cost NPCs and a full profile for important agents.

### 25.1 Population scaling

The system must not assume that every NPC requires an identical neural population.

Implement configurable profiles:

- Minimal: basic perception, reflexes, homeostasis and action selection.
- Standard: all major anatomical systems with bounded populations and memory.
- Full: expanded cognitive, memory, social and planning capacities.

Profiles must preserve the same architecture and behavioral interfaces.

They may differ in processing capacity, not in the fundamental laws governing the brain.

## 26. AVX2 Optimization

Implement optimized kernels for:

- Synaptic accumulation.
- Membrane updates.
- Trace updates.
- Weight updates.
- Integer decay.
- Population-level modulation.

Use AVX2 only where it produces measurable benefits.

Important: AVX2 does not provide AVX-VNNI integer dot-product instructions. Implement exact integer accumulation using safe widening and multiply-add operations.

Avoid saturating intermediate arithmetic unless saturation is explicitly part of the mathematical specification.

Scalar fallback must produce bit-identical results.

## 27. Performance Requirements

Benchmark against the previous CL-1 implementation.

Measure:

- Cycles per NPC.
- Cycles per active neuron.
- Synaptic operations.
- Average active spike ratio.
- Memory per NPC.
- Cache misses.
- Scheduler overhead.
- Cognitive rollout cost.
- Save/load performance.

Target sparse firing rate: approximately 1–5% during ordinary low/moderate activity.

This is a target, not a hard-coded firing restriction.

The 5–10x throughput improvement must be demonstrated through benchmarks rather than assumed.

Include:

- Neural membrane potentials.
- Spike masks.
- Refractory states.
- Synaptic weights.
- Delayed spike buffers.
- Plasticity traces.
- Neuromodulators.
- Emotional state.

- Memory records.
- Memory indices affecting retrieval.
- Learning parameters.
- Goal state.
- Scheduler state.
- Pending neural events.

Do not hash:
- Pointers.
- Memory addresses.
- Padding bytes.
- Uninitialized memory.

Hash logical state in canonical order.

The implementation is not complete merely because all 12 modules exist.

The following conditions must all be satisfied:

1. All 12 anatomical-functional systems are implemented.
2. All major neural pathways are represented.
3. All neural processing uses deterministic integer arithmetic.
4. Sensory input is dynamically configurable.
5. The brain cannot access hidden world information.
6. Memory is independent from the neural substrate.
7. NPCs can learn through experience.
8. NPCs can form and revise knowledge.
9. NPCs can learn from failure and observation.
10. NPCs can develop emotional responses.
11. NPCs can form goals and resolve conflicts.
12. NPCs can perform bounded multi-step planning.
13. NPCs can learn motor skills.
14. NPCs can acquire and communicate language knowledge.
15. Neural traits can be inherited.
16. Learned knowledge is not automatically inherited.
17. Neural activity is sparse and event-driven.
18. CPU processing is bounded.
19. Hot paths allocate no heap memory.
20. AVX2 and scalar implementations are bit-identical.
21. Single-thread and multi-thread executions are bit-identical.
22. Save/load preserves the complete neural state.
23. state_hash() covers all future-affecting persistent state.
24. Existing Sunnyworld systems remain compatible.
25. All existing regression tests pass.

## FINAL ENGINEERING DIRECTIVE

Do not implement this specification as 12 independent artificial intelligence modules.

Implement one integrated neural system with:

- Shared neural substrate.
- Anatomically organized populations.
- Directed sparse connectome.
- Distributed memory and cognition.
- Shared neuromodulatory systems.
- Event-driven communication.
- Experience-dependent plasticity.

Anatomical modules must interact through explicit neural pathways rather than directly invoking each other's private functions.

Do not create predefined intelligence, knowledge, technology, recipes, survival strategies or behavioral scripts.

The brain must provide the mechanisms through which intelligence and behavior emerge from the interaction between inherited neural architecture, sensory experience, memory, learning, environmental constraints and social interaction.

**Primary engineering principle:**

The world determines what is physically possible. The brain determines what an NPC perceives, remembers, learns, predicts, desires and decides. The action system determines what it can actually execute.

Preserve this separation throughout the implementation.

**Do not sacrifice determinism, causal correctness or long-term extensibility for short-term performance.**
