# narrative_templates.txt — Emergent Narrative Chronicle (Phase 15)
# Every sentence the Live Feed / floating callouts / inspector life-story
# shows is composed from REAL causal-ledger events through these patterns.
# No script, no trigger: change the data, the storytelling changes.
#
# Format (fields separated by '|', '#' starts a comment):
#   key | category | callout | template
#
#   key      verb ("strike"), qualified verb ("strike:wound" — picked first
#            when the event carries that qualifier), "spawn:<kind>" for an
#            entity born from the event, or "*" as the fallback for any
#            narratable verb without its own rule.
#   category combat | survival | discovery | society | other  (OR-able:
#            "combat|society") — drives the feed's quick filters.
#   callout  1 = also float the line above the actor on the map for ~4 s.
#   template free text with {slots} resolved against World Truth:
#
#     {actor}   "#42 human" — short id + what it is
#     {about}   "#7 wolf" — second participant (target/victim/guest)
#     {item}    wielded tool/weapon in the actor's hands, or "bare hands"
#     {part}    anatomy role that took the blow ("left arm", "skull"...)
#     {qty}     amount involved (goods moved, fruit eaten, ammo spent)
#     {mat}     material name of the target/spawned thing
#     {pct}     integrity percent after the change ("37%")
#     {word}    spoken/carved words, each followed by your Rosetta reading
#     {tongue}  the speaker's tongue id
#     {claim}   the hypothesis a verified discovery proved
#     {charge}  emotional colour of a memory ("in fear", "in love"...)
#     {when}    "d12 07h" — world day + hour of the event
#     {failure} why an attempt failed, in plain words
#     {site}    name/kind of the enclosure or place involved, if any
#
# Multiple lines per key = variants; one is picked deterministically by
# (tick, key) so replays tell the same story.
