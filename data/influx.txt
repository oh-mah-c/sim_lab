# Sunnyworld edge influx — migrants cross declared boundary zones. DATA ONLY:
# the engine runs one generic loop; an empty file (or a zone with no
# templates) means the world stays empty after collapse. A zone fires when
# hash(world_seed, zone, tick) % interval == 0 — irregular but deterministic —
# and only while fewer than `capacity` migrant-kind entities live inside
# `bounds`. Each migrant template is a full phenotype: material, props,
# genome loci (`gene`), and optional `innate` verbs — a sapient migrant is
# born with an AgentMind holding ONLY those instincts; everything else
# (craft, writing, the old tribe's mistakes) must be learned by contact or
# rediscovered among the ruins.
#
# Format:
#   influx_zone <name>
#     bounds <x0> <y0> <x1> <y1>
#     interval <ticks>
#     capacity <n>
#     migrants <n>
#     migrant <name>
#       kind <kind_name>
#       material <material_name>     # optional
#       prop <name> <value>          # repeatable
#       gene <prop_name> <allele>    # repeatable
#       innate <verb>                # repeatable

# Northern pass — a fertile neighbouring valley sends forager bands.
# Genome loci match the founder set so migrants stay reproductively
# compatible with any surviving lineages.

  bounds 2000 -600 2600 600
