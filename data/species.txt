# Sunnyworld species / ecology registry — WORLD TRUTH habitat data (TODO §2.1 Ecology).
# A species is a habitat rule: where an organism can live, not a spawn list.
# Worldgen places an individual only where EVERY condition holds (analytic
# climate/terrain fields) and a per-cell hash passes `density`.
#
# Format:
#   species <name>
#     kind flora|fauna          # flora: one per cell (first matching species wins)
#     material <material_name>
#     density <permille>        # chance per eligible cell
#     condition <field> <lo> <hi>
#         fields: elevation moisture temperature slope near_water
#                 vegetation water_table fault
#     <prop_name> <value>       # any registered property, applied to the entity
#
# Names containing "tree" are conventionally woody plants.

# Berry bush — the base of the food chain. TWO LAYERS:
#   body : living_wood (integrity 1000, decay_rate 0) — dies only to physical
#          or thermal damage, never because its fruit is eaten or spoils.
#   fruit: `fruit_material wild_berries` hanging as `fruit_count` (cap
#          `max_fruit`). `consume` reads nutrition/hydration from the FRUIT
#          material and takes one fruit; a bare bush refuses `consume`.
# Fruit drift (World::drift_needs, exact under dormant-LOD batching):
#   + fruit_regrow_rate milli-fruit/tick x local moisture*temperature
#     suitability (500/1000 without a terrain field), capped at max_fruit
#   - fruit_spoil_rate milli-fruit/tick (old fruit drops), floored at 0
# Regrowth must outpace spoilage in good habitat or the bush stays bare:
# 120 x 0.5 - 15 = +45 milli/tick -> a stripped bush is full again in ~900
# ticks; at the habitat fringe (low suitability) fruiting stays sparse.
species berry_bush
  kind flora
  material living_wood
  fruit_material wild_berries
  fruit_count 40
  max_fruit 40
  fruit_regrow_rate 120
  fruit_spoil_rate 15
  death_drops dormant_seed=4,wood_debris=1
  density 120
  condition temperature -100 400
  condition moisture 300 1000
  condition vegetation 400 1000
