# Sunnyworld deposit registry — WORLD TRUTH data (TODO §2, §9).
# A deposit is a natural occurrence: composition, physical properties,
# accessibility, and FORMATION CONDITIONS (where it may exist).
# Agents must DISCOVER it; nothing here is agent knowledge.
#
# Format:
#   deposit <name>
#     substance <material_name> <share_permille>   # shares must sum to 1000
#     accessibility surface|buried
#     depth <metres>
#     condition <field> <lo> <hi>                  # repeatable
#         fields: elevation(m) moisture(‰) temperature(deci-°C)
#                slope(m) near_water(0/1) vegetation(‰) water_table(m)
#                lithology(class) fault(0/1) placer_site(0/1)
#     <prop_name> <value>                          # any registered property
#
# reserve            total extractable units (depletes via extraction, Phase 3)
# yield_rate         extraction yield per 1000 force units (Phase 3)
# min_force          minimum force to break material loose (Phase 3)
# dig_resistance     force needed to expose a buried deposit (Phase 3)
# formation_chance   permille per eligible cell during worldgen
